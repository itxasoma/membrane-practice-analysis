# Membrane Practice Analysis

Molecular dynamics analysis of a hydrated **DMPC phospholipid membrane** using NAMD, developed for the *Soft Matter* course (MASM, 2025–2026).

The system consists of 128 DMPC phospholipids and 4 377 water molecules, simulated with the CHARMM36 force field. The analysis covers equilibration diagnostics, production thermodynamics across a temperature scan (290–307 K), dipolar rotational autocorrelation functions of water at different distances from the membrane, and translational diffusion via MSD and VACF.

## Physical system

A bilayer of 128 DMPC (1,2-dimyristoyl-*sn*-glycero-3-phosphocholine) molecules solvated by 4 377 TIP3P water molecules. Simulations are performed with NAMD using the CHARMM36 lipid force field at p = 1 atm.

The temperature scan covers T = 290, 293, 297, 301, 304, 307 K, spanning the gel–fluid phase transition of DMPC (T<sub>m</sub> ≈ 297 K).

***

## Analysis pipeline

### 0 — Equilibration check (`src/equi.py`)

Reads the NAMD `.log` file from the NPT equilibration run and outputs time series and z-score plots for total energy, potential energy, bonded energy, temperature, pressure, and volume. A summary `.dat` file is written to `figures/`.

### 1 — Production thermodynamics (`src/prod.py` + `src/stats.py`)

Reads `.log` files from NVT production runs at each temperature and produces energy, temperature, pressure, and volume plots. Block statistics are used to estimate statistical errors on the mean; output is written to `figures/1.block_stats_<T>.txt`.

### 2 — Dipolar rotational autocorrelation function (`src/corr.py` + `src/corr-plots.py`)

Computes the normalised DRACF

$$C_\mathrm{rot}(\delta t) = \frac{\langle \hat{\mu}(t) \cdot \hat{\mu}(t+\delta t) \rangle - \langle \hat{\mu} \rangle^2}{\langle \hat{\mu}^2 \rangle - \langle \hat{\mu} \rangle^2}$$

for water molecules binned by distance to the nearest lipid atom: 0–3 Å, 3–5 Å, 5–10 Å, 10–15 Å. Results are computed for each temperature of the scan and saved as `.csv` + `.pdf` in `figures/`.

The trajectory conversion from binary `.dcd` to `.xyz` format is handled by `1_Analysis/trajectory_to_xyz.py` (reference run) and `1_Analysis/trajectory_to_xyz_tscan.py` (temperature scan), both using VMD's Python interface.

### 3 — Translational diffusion (`src/prod.py`)

Computes the mean squared displacement (MSD) of oxygen atoms, the velocity autocorrelation function (VACF), and the MSD decomposed by distance shell to the membrane. Output in `figures/3a.msd.*`, `figures/3b.vacf.*`, `figures/3c.msd_per_slice.*`.

## Requirements

### NAMD ≥ 2.12
Required only to re-run simulations. See [NAMD documentation](http://www.ks.uiuc.edu/Research/namd/).

### VMD
Required for trajectory conversion (`.dcd` → `.xyz`). See [VMD download](https://www.ks.uiuc.edu/Research/vmd/).

### Python ≥ 3.9

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r src/lib/requirements.txt
```

## How to run the analysis

All analysis scripts assume that `.xyz` trajectory files have already been generated (see `1_Analysis/`).

```bash
# From the repository root:
cd src

# Equilibration diagnostics
python equi.py

# Production thermodynamics (all temperatures)
python prod.py

# Correlation functions
python corr.py
python corr-plots.py
```

Or use the Makefile convenience targets:

```bash
make equi
make prod
make corr
```

Output figures and data are written to `figures/`.

## Notes on the TSCAN folder

`TSCAN/` contains `.xyz` trajectory files at T = 293.5, 297.5, 301.5, 304.5, and 307.5 K contributed by collaborators in the course. These are the input for the correlation function and diffusion analyses. The folder naming convention is `<T>-<contributor>`.
